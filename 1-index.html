Fer la pràctica: 14 preguntes

1. Tipus de variables

Una variable és la característica que estudiem: color dels ulls, alçada, nombre de germans...

  • Qualitativa: descriu categories, no quantitats. Exemples: color dels ulls, esport preferit.
  • Quantitativa discreta: una quantitat que es compta. Exemple: nombre de germans (0, 1, 2...).
  • Quantitativa contínua: una quantitat que es mesura. Exemples: alçada, pes, temps. Pot prendre valors intermedis.
Un número també pot ser una etiquetaEl dorsal d’un jugador identifica, no mesura una quantitat. No tot el que s’escriu amb xifres és una variable quantitativa.

2. Freqüències

La freqüència indica quantes vegades apareix un valor. No és un tipus de variable.

  • Absoluta (f): nombre de vegades que apareix el valor.
  • Relativa (h): freqüència absoluta ÷ nombre total de dades (N).
  • Percentatge: freqüència relativa × 100.
Exemple: 6 de 20 alumnes trien futbol

Absoluta = 6. Relativa = 6/20 = 0,3. Percentatge = 30%.

Comprovació: les freqüències absolutes sumen N; les relatives sumen 1 (o 100%). Si has arrodonit, pot sortir una mica diferent.

No confonguis les paraulesQualitativa descriu la variable. Relativa descriu una freqüència. Una variable qualitativa també té freqüències relatives.

3. Moda, mitjana i mediana

Moda: el més repetit

És el valor amb més freqüència. Si dos valors empaten com els més freqüents, hi ha dues modes. Si cap destaca, a nivell escolar es diu que no hi ha moda.

Mitjana: sumar i dividir

Suma TOTES les dades i divideix pel nombre TOTAL de dades, no pel nombre de valors diferents.

Mediana: ordenar i buscar el centre
  • Primer ordena les dades de menor a major.
  • Si hi ha un nombre senar de dades, agafa la dada central.
  • Si hi ha un nombre parell, fes la mitjana de les dues dades centrals.
Exemple complet: 2, 3, 3, 6, 11

Moda = 3 (surt dos cops). Mitjana = (2+3+3+6+11)/5 = 25/5 = 5. Mediana = 3 (tercera dada de cinc).

Exemple parell: 2, 4, 7, 9

Mediana = (4+7)/2 = 5,5. No ha de coincidir amb cap de les dades.

4. Si tens una taula

Multiplica cada valor per la seva freqüència, suma els resultats i divideix per la suma de freqüències.

Valor 1, freqüència 2; valor 4, freqüència 3. Les dades són 1, 1, 4, 4, 4. Mitjana = (1×2 + 4×3)/5 = 2,8.

Abans de començar

  • Moda = més repetit. Mitjana = sumar i dividir. Mediana = ordenar i centre.
  • La mitjana es calcula amb quantitats, no amb categories com colors.
  • No oblidis ordenar per a la mediana.
  • 0,3 és 30%, no 0,3%.
